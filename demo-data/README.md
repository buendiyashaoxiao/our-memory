# Demo data (entirely fictional)

Generated by `python -m memory_museum generate-demo`. The couple 林夏 & 周屿, their messages, photos, voices
and videos are synthetic: images are procedurally drawn, voices are tone-based placeholders.

It deliberately contains problems the importer must survive: duplicate records, missing and unparseable
timestamps, an unknown message type, junk entries, references to missing files, a corrupted JPEG, a
truncated MP4, an empty audio file, duplicate photos and an unsupported file type.
