# 史实核查 第一轮

核查日期 2026 年 9 月 30 日。

说明。这一轮只能用网络搜索，原始 PDF（黄金海回忆录、王锐论文、李逊论文）和维基、RFA、爱思想等网页都被当前环境的网络策略挡住，没能直接读原文。所以下面的结论大多来自搜索结果对这些页面的摘要，可信度标为“较可靠”的，是多个来源说法一致的；标为“待原文”的，需要有人拿原书或原文再对一遍。

对 demo 的影响。
- `anting` 场景的时间戳写的是“凌晨”，正文写“天还黑着”有人跳下车。按史料，列车8点多停下，卧轨是在中午前后，要改成白天。
- 北上的人其实分成了两批。第一批到了南京，王洪文这一批在安亭。这是个好细节，可以写进去。
- 周月娥坐的应该就是被拦下的14次特快，她去南京，这趟车正好经过南京，设定成立。
- “三十多小时”保留，史料注里补上“一说二十小时”。

对 demo 的影响。
- `table` 场景写成“11月13日夜，安亭车站附近一间办公室”，这是把两件事合在了一起。实际是11日深夜在安亭谈，13日在文化广场签字。建议拆成两个场景，安亭深夜谈判，文化广场签字。
- 场景里“三天了”要改，陈伯达电报到的时候只过了一天多。
- 很重要的一点。按 RFA 的叙述，历史上的王洪文在谈判桌上一直不说话，是潘国平在谈。这和叶永烈写的“王洪文先退一步再提条件”相冲突。游戏正好可以把这两种说法都摆进来，“先退一步”那个选项的史料注要写明两说。
- 不肯回去的那部分人是谁带去苏州的，来源不一致。交接说明写潘国平，有一个来源说是上海纸浆厂的耿金章“一路步行到了苏州”。这关系到第二幕耿金章和“二兵团”的来历，**待原文**，最好查李逊书第九章。

### 3. 五项要求的条文（较可靠）

1. 承认上海市工人革命造反总司令部是合法的组织。
2. 承认“一一·九”大会以及被迫上北京控告是革命的行动。
3. 这次所造成的后果，全部由华东局、上海市委负完全责任。
4. 曹荻秋必须向群众作公开检查。
5. 对上海市工人革命造反总司令部今后工作提供各方面方便。

另有说法这五条是潘国平和红卫兵一起起草的。毛泽东事后说张春桥可以“先斩后奏”。demo 的词条大意正确，可以换成原文。

### 4. 谁第一个下到铁轨

没有找到可靠的一手说法。党史类来源一律写“王洪文等率众卧轨”，这是清查框架下的写法。“王洪文跟在别人后面”的说法仍只见于禁闻网〈昔日潘司令〉。维持“有争议”标签。**待原文**，王锐论文里的1980年审讯笔录可能有答案。

### 5. 王秀珍的判决（较可靠）

1982年8月21日，上海市高级人民法院判处有期徒刑十七年，剥夺政治权利四年，1994年2月刑满释放，2008年去世。出生年份有1934和1935两说。来源是维基“王秀珍 (1934年)”条目、维基文库里的起诉书、知乎〈1982年8月21日“四人帮”上海余党被判刑〉。

### 6. 国棉十七厂的工作队

7月20日，上海市委派出约一百五十人的工作队进驻国棉十七厂，队长是市总工会副主席施惠珍。在这之前局里派过一支，市里的来了以后局里的就撤了。撤出的具体日期没有查到，只知道十月王洪文从北京回来以后工作队被冲垮。来源是 RFA《纵横大历史》工总司成立系列。

对 demo 的影响。`p2` 结尾写“又过了几天，市里派来了工作队”，要改成先有局里的工作队，7月20日市里又派来一支一百五十人的。

## 二、第二幕的基本事实

### 1. 赤卫队成立

1966年11月26日成立，全称“捍卫毛泽东思想工人赤卫队上海总部”，号称最多发展到八十万人。来源是维基〈《解放日报》事件〉条目。

### 2. 解放日报事件（较可靠）

- 11月29日晚，红卫兵“红革会”要求《红卫战报》随《解放日报》一起发行，被拒绝。
- 11月30日凌晨1时左右，红革会组织各校学生冲进汉口路274号解放日报社，占据下面几层，设“前线指挥部”。
- 对峙八天九夜。中央文革指示后双方签了“三项决议”和“四项要求”。12月7日《解放日报》复刊，12月9日造反派陆续撤出。
- 工总司站在红革会一边，赤卫队站在报社一边，两边工人第一次大规模对峙。

来源是维基〈《解放日报》事件〉、RFA《纵横大历史》“打解放日报”一讲、激流网转载的李逊书第五章。

### 3. 康平路事件（较可靠）

| 时间 | 事件 |
|---|---|
| 12月23日 | 赤卫队在人民广场开大会，提出八项要求，曹荻秋签字承认 |
| 12月24日 | 陈丕显主持会议，认为曹荻秋签字是政治立场错误 |
| 12月25日 | 曹荻秋宣布签字作废，称赤卫队是“保皇组织” |
| 此后几天 | 赤卫队员聚到康平路市委书记处，要求说法 |
| 12月28日夜 | 张春桥在北京与妻子李文静通电话 |
| 12月29日早 | 李文静打电话给徐景贤，转达张春桥的意思，说赤卫队造了曹荻秋的反，要各造反组织注意，“不要让赤卫队把胜利的果实夺走了” |
| 12月29日 | 耿金章接到张春桥秘书电话，从北京赶回上海，设临时指挥部，调人去康平路 |
| 12月30日凌晨2时左右 | 造反派开始冲击康平路的赤卫队 |

| 7时 | 近两万名赤卫队员排成单列分六路走出，袖章缴下来堆成六大堆 |
| 12月30日上午 | 王洪文主持会议，布置“砸掉赤卫队各区联络站” |
| 12月30日下午 | 约一万名赤卫队员步行北上，要去北京告状 |

| 1967年1月3日 | 市委书记马天水赶到昆山劝返，最后仍有六七千人去了北京 |

来源是维基〈康平路事件〉、新浪转载的〈张春桥阴谋策划“康平路事件”〉、RFA“激战康平路”一讲。注意，新浪那篇的标题本身就是清查框架，写到张春桥“策划”时要标“有争议”。

对设计的意义。
- 29日早上那个会王洪文没有参加，冲康平路的现场指挥是耿金章。王洪文在这件事里的位置比一般印象要靠后，这给了玩家真实的选择空间。
- 赤卫队的处境很适合做插曲。他们上周刚被市长承认，两天后被市委收回，跑去市委要说法，又被造反派打散，最后步行去北京告状，跟一个半月前的工总司几乎是镜像。老陆可以就是这一万人里的一个。
- 12月30日赤卫队北上被拦在昆山，和11月工总司北上被拦在安亭，完全对称。这个对称应该让玩家亲身走一遍。

### 4. 王维国释放被关押的赤卫队员

搜索只找到一句，说王维国发现市局和各分局关押了很多赤卫队员，理由是“反对王洪文”“反对工总司”。具体时间和经过没有查到。**待原文**，来源应是《记忆》第91期。
