# 《梦与非梦》项目交接说明

> 用法：新开对话时，把这份文件和 `梦与非梦_安亭demo.html` 一起上传，并对 Claude 说“请先完整读完交接说明和 demo 代码，然后我们继续做这个游戏”。下面第一部分可以直接当作开场 prompt 使用。

---

## 一、开场 Prompt（可直接复制）

我在做一款以王洪文为第一视角的中文文字冒险游戏，暂名《梦与非梦》，题材是 1966 至 1976 年的上海文革，重点是工人造反派与保守派。主要依据三部书：黄金海《十年非梦》、徐景贤《十年一梦》、李逊《革命造反年代：上海文革运动史稿》（以及李逊《大崩溃》）。附件里有已经完成的第一幕试玩 demo（单文件 HTML）和这份交接说明。

请你先完整阅读 demo 的代码和本说明，理解已经确定的设计原则、写作风格、代码结构和文献清单，然后按照“下一步工作”继续。所有新内容都要沿用 demo 的结构和文风，交付物是更新后的单文件 HTML。

我的写作偏好：不要用破折号，不要用冒号引出列表，不要用“不是 X 而是 Y”这类句式。

---

## 二、项目目标

- 让玩家以王洪文的视角经历上海文革，**体验历史的复杂性**：造反派和保守派各自的处境与动机，被整的人、整人的人、被卷进来的普通人。
- 给玩家**改变历史的机会**（IF 线），但每条 IF 线都要保留“它为什么没有发生”的答案。玩完所有路线的人，应该比只看史实的人更理解历史为什么是那样。
- 游戏本身也是一次关于**记忆政治**的实验：同一件事有好几种讲法，档案会被改写，当代网络上还有“王洪文热”。

## 三、已确定的设计原则

1. **没有数值。** 不设好感度、群众基础之类的数值面板。游戏只记住“事实”（玩家做过什么），后面的场景、台词、可选项根据这些事实变化。
2. **选项可以被锁住，但理由是叙事性的。** 例如玩家在安亭留在站台劝人别拦车，谈判时“先退一步提条件”这句会变灰，理由写成“你在站台上劝过大家别拦车。在这张桌子前，这句话轮不到你说。”
3. **IF 线是走着走着长出来的。** 玩家不会主动“选择进入巴黎公社线”，而是一系列小选择积累到某个节点时，一个原本不存在的选项自然出现。
4. **档案系统。** 每个关键选择生成一条档案，可以在“1966 年的写法”和“1977 年的写法”之间切换。同一件事，前者写成“坚持斗争”，后者写成“卧轨拦车”。选择回厂的人，1977 年那一栏是空的。
5. **史料透镜。** 每幕结尾用三种立场复述玩家这一局：战友的讲法（仿黄金海立场）、官员的讲法（仿徐景贤立场）、研究者的讲法（仿李逊立场）。**必须注明是仿写，不是原文，不代表作者真实说过这些话**，避免被截图当成真实引语传播。
6. **史料注。** 每一段都有“史料注”，分三类标签：史实、有争议、虚构，并写明出处。
7. **词条系统。** 正文中的重要人物、事件、机构、术语自动加链接（每段只标第一次出现），点击弹出底部词条卡。词条要讲清“这个东西在当时意味着什么”，不只是百科定义。另有“词条”按钮列出已遇到的全部词条。
8. **多视角插曲。** 每幕穿插一段其他人物的可玩视角，尤其是保守派和普通人。第一幕是被拦在安亭客车上的挡车工周月娥（虚构合成人物），旁边坐着厂里的赤卫队员老陆。
9. **受害者必须在场。** 批斗、武斗、审讯的受害者要出现，不能让游戏变成造反爽文。
10. **框架：秦城之梦。** 整个游戏设定为王洪文在秦城监狱反复做的梦。每局醒来回到秦城，页面顶部显示“这是你第 N 次梦见安亭”。历史线是“非梦”，IF 线是“梦”。
11. **真实人物的台词**尽量依据有记载的言论改写，并在史料注里说明出处；无记载的部分标为虚构。

## 四、写作风格要求

- 第二人称“你”，贴着王洪文的感官和处境写。插曲段落开头说明视角切换。
- **先铺垫，再给选择。** 用户特别强调：不能一上来就让玩家做选择。要先写清楚前面发生了什么、为什么大家情绪激动、为什么会聚在一起，而且要通过王洪文的第一视角和别人的具体行动让玩家感受到，不能直接讲道理。
- 叙述克制，不替王洪文辩护，也不丑化他。情绪通过细节传达（签名时手抖、签了又划掉再签上；食堂里筷子停在半空；黄金海讲自己的遭遇时声音很平，一直在抽烟）。
- 序章类段落只给一个“继续”按钮，但按钮文字本身是叙述，比如“你以为工作队是来支持你们的。”
- 避免破折号、避免冒号引出列表、避免“不是 X 而是 Y”。

代码结构要点：

- `SC[键名] = { stamp, place, title, persona?, end?, text: ()=>HTML, choices: [...] 或 ()=>[...], src: HTML }`
- 每个选项：`{ t: 文字或函数, set: 事实标记或 null, a66: 1966 年档案文字或 null, a77: 1977 年档案文字或 null, next: 下一场景, lock: 锁定理由或 null }`
- `st.facts` 存事实标记，`has("xxx")` 判断；`st.archive` 存档案；`st.seen` 存已见词条。
- `GLOSS[key] = { m: [正文中匹配的词], t: 词条标题, b: 解释 }`，`gloss(html)` 自动给第一次出现的词加链接。
- `lensText(which)` 生成三种讲法，`relLines()` 生成人物结局，`outcome()` 汇总结局类型。
- 已有事实标记：lead_self / lead_pan / lead_col，go_north / wait_cmte / go_home，on_tracks / followed / dissent，talked / stayed，deal / hard / let_pan / go_back。
- 视觉：冷灰绿纸面，复写纸蓝作强调色，思源宋体正文，IBM Plex Mono 用于档案和日期；选项做成带虚线撕边的“单据”；支持深浅色主题。

## 六、全局大纲（初步，可调整）

- **序章** 1966.6 国棉十七厂（已完成，并入第一幕）
- **第一幕 安亭** 1966.11（已完成试玩）
- **第二幕 夺权** 1966.12 至 1967.2：解放日报事件、康平路事件（工总司对赤卫队）、一月风暴、“上海人民公社”改名革委会（李逊“巴黎公社原则的蜕变”在这里变成玩法）
- **第三幕 体制化** 1967 至 1972：1967.8 砸上柴联司（造反派打造反派）、耿金章二兵团、潘国平被边缘化、工人当干部后的工资住房问题、九大
- **第四幕 接班人** 1972 至 1976：进京住钓鱼台、《刘盆子传》与朱永嘉讲解、十大副主席、1974 长沙告状、1975 邓小平主持工作后回上海失意
- **第五幕 十月** 1976：毛病危守候、怀仁堂、上海“第二武装”问题
- **第六幕 审判与秦城** 1976 至 1992：隔离审查、档案清算、认罪或抗辩、与邱会作等人同监
- **尾声 小王同志** 2020 年代：当代青年刷到王洪文梗图，玩家的选择影响他看到什么

多视角插曲候选：赤卫队工人、黄金海、潘国平、陈丕显或曹荻秋、马骥（王洪文同事、对立派负责人）、徐景贤、联司成员。

## 七、IF 线（由事实积累自然触发，不设数值门槛）

| IF 线 | 大致分歧点 | 需要保留的复杂性 |
|---|---|---|
| 真巴黎公社 | 1967.2 拒绝把“上海人民公社”改名，坚持普选和罢免 | 生产下滑、派系争票、军队态度、选出来的人是否变成新官僚；结局可能是军管、官僚化或全国公社割据 |
| 僵化线（四人帮胜出） | 1976.10 提前察觉怀仁堂安排，或争取到华国锋、汪东兴 | 赢了也不是好结局：停滞、危机、是否下令镇压、类似苏联的解体 |
| 江青“女皇”线 | 1974 至 1976 完全投靠江青 | 宫廷政治；同时审视 1976 年后批判江青时“女皇”“吕后”比附的性别化叙事 |
| 工人改革线 | 1975 与邓小平合作 | 市场化中保护工人的尝试，连接 90 年代下岗潮 |
| 上海武装线 | 1976.10 “第二武装”真的启动 | 只有悲剧结局，逐一展示民兵是谁、家人后来怎样 |
| 回厂线 | 任何时候辞职回厂拿 64 元（第一幕已有雏形） | 退出也不能让人免于历史：清查、下岗、一辈子背着身份 |
| 保派线 | 序章不签大字报，或被赤卫队争取 | 从另一边看工总司，平反与提拔，两边在争同一个东西 |
| 张春桥接班线 | 全力辅佐张春桥 | 更理论化、更有组织的文革路线，对异见的处理可能更系统 |

小型 IF 节点：让潘国平当司令、康平路阻止冲击市委、1967.8 不砸联司、1971 林彪事件前后站队、1974 不去长沙、审判时拒绝认罪等。

## 十、第一幕用到的史实时间线（速查）

- 1966.6.1 中央人民广播电台播出聂元梓大字报，次日《人民日报》刊登
- 1966.6.12 王洪文起草《剥开画皮看真相》，七人签名
- 1966.7-10 工作队进驻国棉十七厂，四次全厂大辩论；10.10 王洪文被围，廖祖康带学生解围
- 1966.8.8 《十六条》通过
- 1966.10 《红旗》社论与中央工作会议提出批判“资产阶级反动路线”；王洪文赴京告状
- 1966.11.6 愚园路 311 号开会，决定成立工总司
- 1966.11.9 文化广场成立大会，市委“三不”，曹荻秋未到，会场混乱，潘国平被撤下改由张宝林主持；当夜北上
- 1966.11.10 列车停于安亭，工人卧轨拦车，沪宁线中断三十多小时
- 陈伯达来电劝返
- 1966.11.13 张春桥签五项要求，承认工总司合法、安亭事件为革命行动；王洪文带多数人回沪，潘国平带部分人去苏州
