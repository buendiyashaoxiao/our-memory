# 小红书宣传片（竖屏 1080×1920 · 37 秒）

成片：`promo.mp4`（静音轨，可在小红书/剪映里加 BGM 和你自己的配音）

## 配音稿（按时间对口型录）

| 时间 | 画面 | 配音 / 字幕 |
|---|---|---|
| 0–4s | 手写大字「这道题 / 90%的人 / 第一步就列错了」 | 这道连串滑轮题，90% 的人第一步就列错了 |
| 4–8s | 一笔一划画出滑轮、绳子、m₁、m₂ | 先别急着列方程，把图画出来 |
| 8–12s | 逐个标出 T₁、T₂、m₁g、m₂g、α | 每个物体，受力一个一个标清楚 |
| 12–16s | 写出 T₁ = T₂ ?，红笔打叉 | 最常见的错：以为两边拉力一样大 |
| 16–20s | 写出方程 ①②③ | 滑轮有质量，就得多列一个转动方程 |
| 20–23s | 写出 ④ 和最终结果 a = (m₁−m₂)g/(m₁+m₂+M/2) | 四个方程联立，加速度直接出来 |
| 23–27s | 弹出「一句话核心套路」卡片 | 记住这一句，同类题全都能套 |
| 27–33s | 账号介绍：每期 3 分钟 / 手写推导 / 受力图 / 一句话套路 | 每期一道难题，手写推导，一句话讲透 |
| 33–37s | 「下一道题见」+ @账号名 + 关注按钮 | 关注我，下一道题见 |

## 修改后重新生成

1. 改 `promo.html`（账号名搜索「@你的账号名」；时间轴在底部 `writes` / `caps` 里）。
   直接用浏览器打开 `promo.html` 可以循环预览。
2. 下载字体到 `fonts/`：`wenkai-400.ttf`、`wenkai-700.ttf`（LXGW WenKai TC）、`mashanzheng.ttf`（Ma Shan Zheng），均来自 Google Fonts。
3. `node render.mjs` 逐帧渲染并输出 `promo.mp4`（需要 Playwright + ffmpeg，ffmpeg 路径可用 `FFMPEG` 环境变量指定）。
   `node render.mjs --stills 3,12,25` 可只导出几张截图检查排版。
